Installer Mon Cabinet AD

⚠ Attention : lien valable pour 1 seule activation.
À installer sur l'ordinateur du cabinet que vous utilisez personnellement.

  1. Cliquez sur « Télécharger », puis ouvrez le fichier téléchargé.
  2. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur « Informations complémentaires » puis « Exécuter quand même ».
  3. Cliquez sur « Installer » et acceptez l'autorisation Windows.

Ne renommez pas le fichier téléchargé : il contient votre code d'activation. Une question ? 04 69 96 03 60
