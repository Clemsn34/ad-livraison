# AD Livraison

Application téléphone d'Alternative Dentaire Consommable : préparation des commandes au stockage
(scan des codes-barres) et vérification chez le praticien (signature, photo, bon de livraison PDF).

Les données sont stockées dans le Google Sheet « Licences Consommables Alternative Dentaire »
(service Apps Script). Connexion avec le code d'accès personnel du logiciel.
