Installer Mon Cabinet AD

  1. Tapez votre code et cliquez sur « Mon Cabinet AD », puis ouvrez le fichier téléchargé.
  2. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur « Informations complémentaires » puis « Exécuter quand même ».
  3. Indiquez le nom du cabinet et cliquez sur « Installer ». Acceptez l'autorisation Windows (compte administrateur).
  4. C'est fini : l'encadré Alternative Dentaire apparaît sur le Bureau. À faire sur chaque PC du cabinet.

Kit de réparation (collaborateurs)

  1. Décompressez le fichier .zip (clic droit > Extraire tout) sur une clé USB ou le Bureau.
  2. Ouvrez Programmes, puis « Alternative Dentaire Technicien.exe ». Tapez votre code personnel : avec Internet, le programme se met à jour tout seul.
